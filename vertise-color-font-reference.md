# Vertise — Final Color & Typography Reference

## Colors

Sampled directly from the client's logo pixels (not approximated). Background changed from black to navy/indigo per client decision. Gold removed as primary accent per client decision.

| Role | Color | Hex |
|---|---|---|
| Dark section background (was black — now navy/indigo) | Deep navy/indigo | `#0B0F2A` |
| Deep footer background | Darker navy | `#070A1D` |
| Light section background | Soft blue tint | `#E8ECFB` |
| Text on dark sections | Off-white | `#F5F3F0` |
| Text on light sections | Deep ink | `#12142B` |
| **Primary accent** (replaces gold) | Logo red, exact-sampled | `#E12021` |
| Secondary accent | Logo blue, exact-sampled | `#3758FB` |
| Tertiary accent | Logo green, exact-sampled | `#6AD049` |
| Quaternary accent (used sparingly — no longer primary) | Logo gold, exact-sampled | `#FDD80E` |

**Notes:**
- Black is still used, but only for small elements (icons, borders, text-on-light, shadows) — not as a section background.
- Blue is kept as an accent color even though the background is now blue-tinted; use it carefully (icons, badges, secondary buttons) since a blue CTA on a navy background will have low contrast. Red is the primary CTA color for that reason.
- Gold is not removed entirely — it's demoted to a minor/tertiary accent (small icon fills, tiny highlights) rather than the primary button/CTA color.
